# Excel题目导入模板说明

## 模板格式

请按照以下格式创建Excel文件（.xlsx或.xls格式）：

| 分类ID | 题目内容 | 题目类型 | 难度 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 正确答案 | 解析 | 标签 |
|--------|----------|----------|------|-------|-------|-------|-------|-------|-------|----------|------|------|
| 1 | Java中哪个关键字用于定义类？ | 1 | 1 | class | struct | define | type | | | A | class关键字用于定义类 | Java,基础,关键字 |

## 字段说明

### 必填字段
- **分类ID**: 题目所属分类的ID（参考下方分类列表）
- **题目内容**: 题目的具体内容
- **正确答案**: 正确答案的选项字母（A-F）

### 可选字段
- **题目类型**: 1=单选题（默认），2=多选题
- **难度**: 1=简单，2=中等（默认），3=困难
- **选项A-F**: 各选项的内容（至少需要2个选项）
- **解析**: 答案解析说明
- **标签**: 多个标签用逗号分隔

## 注意事项

1. Excel文件第一行必须是表头
2. 表头名称必须与模板一致
3. 文件大小不超过5MB
4. 建议每次导入不超过1000条题目
5. 正确答案必须是A-F之间的字母（不区分大小写）
6. 选项内容不能为空（至少填写选项A和选项B）

## 导入步骤

1. 在后台管理系统点击"题目管理"
2. 点击"批量导入"按钮
3. 选择准备好的Excel文件
4. 等待导入完成
5. 查看导入结果（成功/失败数量及错误信息）
