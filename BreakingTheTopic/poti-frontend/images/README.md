# 图片资源目录

此目录用于存放小程序中使用的图片资源。

## 需要的图标文件

### 底部导航栏图标
- home.png - 首页图标
- home-active.png - 首页选中图标
- question.png - 题库图标
- question-active.png - 题库选中图标
- practice.png - 刷题图标
- practice-active.png - 刷题选中图标
- user.png - 用户图标
- user-active.png - 用户选中图标

### 功能图标
- question-icon.png - 题目功能图标
- practice-icon.png - 刷题功能图标
- wrongbook-icon.png - 错题本图标
- favorite-icon.png - 收藏图标
- interview-icon.png - 面试图标

### 题目分类图标
- java-icon.png - Java 分类图标
- python-icon.png - Python 分类图标
- mysql-icon.png - MySQL 分类图标
- redis-icon.png - Redis 分类图标

### 面试类型图标
- basic-icon.png - 基础面试图标
- advanced-icon.png - 进阶面试图标
- algorithm-icon.png - 算法面试图标

### 其他
- logo.png - 应用 Logo
- default-avatar.png - 默认头像

## 图标规格建议
- 底部导航栏图标：81px × 81px
- 功能图标：60px × 60px
- 分类图标：50px × 50px
- Logo：120px × 120px
- 头像：80px × 80px

## 注意事项
1. 图标建议使用 PNG 格式
2. 建议使用透明背景
3. 图标颜色应与应用主题色一致
4. 可以使用 Vant Weapp 的图标作为参考
