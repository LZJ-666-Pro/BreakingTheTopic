## 0. 个人开发者说明（微信支付）

本项目为个人开发者，**没有微信支付商户号**。无需任何操作：
- 商户参数全部留空，`WX_PAY_ENABLED` 保持默认 `false`
- 项目内置自动降级：未配置商户参数时走**模拟支付**（虚拟扣款，点击支付即开通会员），功能闭环完整
- 未来若开通商户：填 `WX_PAY_MCH_ID / WX_PAY_SERIAL_NO / WX_PAY_APIV3_KEY / WX_PAY_PRIVATE_KEY_PATH / WX_PAY_NOTIFY_URL` 五项 + `WX_PAY_ENABLED=true`，不改代码即切换真实支付

注意区分：`WX_SECRET` 是**小程序 AppSecret**（wx.login 登录必需，个人开发者也有），不是支付商户密钥，必须配置。

## 1. 密钥轮换（最高优先级）

所有密钥均为 `${环境变量:默认值}` 结构，**代码零修改**，用环境变量覆盖即可。
真实密钥值见同目录 `secrets.env`（已 gitignore，严禁提交/外传）。

| 环境变量 | 说明 | 默认值风险 | 动作 |
|---|---|---|---|
| `JWT_SECRET` | 用户/管理员 JWT 签名密钥 | 弱默认且已入 git 历史 | 设为 secrets.env 中的新值 |
| `INTERNAL_TOKEN` | 服务间 internal 接口令牌（8 服务共用） | 已入 git 历史 | 设为 secrets.env 中的新值 |
| `AI_API_KEY` | 智谱 API 密钥（Agent/批量出题） | **真实密钥已入库** | ⚠️ 先去智谱控制台**作废旧 key 并重发**，再填新 key |
| `DB_PASSWORD` | MySQL 密码 | 生产禁用 123456 | 服务器 MySQL 改密 + secrets.env 新值 |
| `WX_APPID` / `WX_SECRET` | 小程序 AppID / AppSecret | 已入库（泄露影响登录） | 微信公众平台「开发管理→开发设置」重置 AppSecret 后填新值 |
| `WX_PAY_ENABLED` | 支付开关 | false | 个人开发者保持 false（模拟支付） |

应用方式（二选一）：
- systemd/docker：`EnvironmentFile=deploy/secrets.env` 或 compose `env_file`
- 手动启动：PowerShell 先 `. .\deploy\load-secrets.ps1` 再 `java -jar ...`
